     7→     7→
     8→     8→## 1. Problemática original
     9→     9→
    10→    10→El negocio factura todos los días usando un archivo de Excel que se volvió
    11→    11→inmanejable: acumula aproximadamente **8,000 hojas independientes**, una por
    12→    12→cada factura emitida.
    13→    13→
    14→    14→**Proceso manual actual:**
    15→    15→1. El operador copia la última hoja existente (ej. la hoja N° 8000).
    16→    16→2. La pega a continuación, generando la hoja 8001.
    17→    17→3. Reescribe sobre la misma plantilla los datos de la nueva transacción
    18→    18→   (tipo de factura, número, fecha, cliente, productos, cantidades, costos,
    19→    19→   total).
    20→    20→
    21→    21→**El problema de fondo:** ese flujo de "copiar, pegar y formatear" no
    22→    22→alimenta ninguna base de datos centralizada. Toda la información queda
    23→    23→atrapada en hojas sueltas, sin forma de consultarla, filtrarla, o sacar
    24→    24→reportes (ventas por cliente, por producto, por período, etc.). Es
    25→    25→imposible hacer seguimiento eficiente del negocio así.
    26→    26→
    27→    27→## 2. Objetivo final
    28→    28→
    29→    29→Lograr una **base de datos centralizada** (dentro del mismo Excel, en una
    30→    30→hoja tipo tabla) que se complete automáticamente cada vez que se emite una
    31→    31→factura, sin que el operador tenga que cambiar su forma de trabajar
    32→    32→(sigue copiando y completando la plantilla como siempre).
    33→    33→
    34→    34→La base de datos debe permitir visualizar, por cada línea de producto
    35→    35→facturado:
    36→    36→
    37→    37→- Número de Factura
    38→    38→- Fecha de Emisión
    39→    39→- Nombre del Cliente (ignorando DNI/CUIT/Dirección — solo el nombre)
    40→    40→- Cantidad de productos emitidos
    41→    41→- Descripción/Nombre del producto emitido
    42→    42→- Costo de dicho producto
    43→    43→- Total de la factura
    44→    44→
    45→    45→## 3. Estructura de una factura (los 7 puntos clave a capturar)
    46→    46→
    47→    47→Independientemente de si es factura tipo A, B, C, o un comprobante manual,
    48→    48→visualmente todas comparten una estructura con estos 7 elementos:
    49→    49→
    50→    50→1. **Tipo de Factura** — letra (A, B, C, M, T, F), ubicada típicamente en el
    51→    51→   centro superior del documento.
    52→    52→2. **Número de Factura** — código numérico completo, debe capturarse entero
    53→    53→   para trazabilidad.
    54→    54→3. **Fecha de Emisión** — fecha exacta del comprobante.
    55→    55→4. **Datos del Cliente** — de todo el bloque de datos del cliente (razón
    56→    56→   social, domicilio, CUIT, etc.), **solo se exporta el Nombre/Razón Social**
    57→    57→   a la base central.
    58→    58→5. **Producto / Servicio** — descripción del ítem facturado en esa línea.
    59→    59→6. **Cantidad** — unidades emitidas de ese producto.
    60→    60→7. **Total y Costo** — el costo unitario del producto, y más abajo en la
    61→    61→   factura, el importe final (suma de cantidad × valor + impuestos).
    62→    62→

    69→    69→  encabezado con tipo y número de comprobante, datos del emisor, datos del
    70→    70→  receptor (Razón Social, Domicilio, CUIT, etc.), tabla de productos

    73→    73→
    74→    74→- **Imagen 2**: una factura tipo **C** (monotributo/consumidor final),

    78→    78→
    79→    79→  > **Conclusión de ambas imágenes**: sirven como referencia de qué datos

    87→    87→  - "FACTURA" + número (ej. `FC-0005`)
    88→    88→  - Fecha (ej. `11/02/21`)
    89→    89→  - Bloque "CLIENTE / DIRECCION / CONTACTO"

    97→    97→  no se confirmó cómo se ve la hoja Excel real con la que trabaja el
    98→    98→  operador, ni si las etiquetas de texto coinciden exactamente con las del
    99→    99→  dibujo.
   100→   100→
   101→   101→## 4. Desafío técnico identificado por el usuario
   102→   102→
   103→   103→Las facturas pueden variar entre formatos (A, B, C, CBA, manual), pero en
   104→   104→teoría todas se llevan a un formato estándar dentro de Excel. El problema
   105→   105→real que el usuario detectó es que **la posición del Total y de las filas
   106→   106→de producto varía según cuántos productos tenga la factura** (si hay 1
   107→   107→producto el total está más arriba, si hay 10 está más abajo). Esto hace
   108→   108→inviable cualquier solución basada en celdas fijas (ej. "el total siempre
   109→   109→está en B45").
   110→   110→
   111→   111→## 5. Solución propuesta y por qué fue la mejor opción
   112→   112→
   113→   113→Evalué varias alternativas (migrar a una app externa, usar OCR sobre PDFs,
   114→   114→una base de datos SQL aparte, Power Query, etc.) y **la opción que elegí
   115→   115→como la mejor para este caso fue: una macro VBA dentro del mismo Excel,
   116→   116→que lea los datos buscando etiquetas de texto (no posiciones fijas de
   117→   117→celda), y los vuelque a una hoja `BaseDeDatos` con formato de tabla.**
   118→   118→
   119→   119→**Por qué esta fue la mejor decisión, comparado con las alternativas:**
   120→   120→
   121→   121→- **Vs. migrar a una plataforma nueva (ERP, app web, etc.):** el operador
   122→   122→  no cambia su forma de trabajar (sigue copiando la plantilla de Excel como
   123→   123→  siempre), cero curva de aprendizaje, cero costo de licencias, y no hay
   124→   124→  riesgo de resistencia al cambio por parte del operador.
   125→   125→- **Vs. OCR / lectura de imagen:** como el operador trabaja directamente
   126→   126→  sobre celdas de Excel (no PDFs ni fotos escaneadas), los datos ya están
   127→   127→  como texto/número real. Usar OCR sería innecesariamente complejo, más
   128→   128→  lento, y propenso a errores de lectura que VBA no tiene.
   129→   129→- **Vs. posiciones de celda fijas (ej. macro que lee siempre `B45`):** esto
   130→   130→  se rompe apenas la cantidad de productos cambia y el Total se desplaza.
   131→   131→  Por eso la solución usa **búsqueda de anclas de texto** (`.Find` de VBA):
   132→   132→  busca palabras clave como "FACTURA", "CLIENTE", "PRODUCTO", "CANTIDAD",
   133→   133→  "VALOR", "TOTAL" en cualquier parte de la hoja, y lee el dato vecino a
   134→   134→  esa palabra. Esto hace que funcione sin importar si hay 1 producto o 30,
   135→   135→  y sin importar pequeñas variaciones de layout entre formatos A/B/C/manual,
   136→   136→  siempre que las etiquetas de texto se mantengan.
   137→   137→- **Vs. una base de datos externa (SQL, Access) desde el día uno:** quise
   138→   138→  evitar sobre-ingenierizar un problema que todavía no tiene la plantilla
   139→   139→  real confirmada. Excel + VBA permite iterar rápido y, si en el futuro se
   140→   140→  necesita escalar a múltiples usuarios concurrentes, la misma lógica de
   141→   141→  extracción se puede redirigir a una base SQLite/SQL sin rehacer todo.
   142→   142→
   143→   143→## 6. Blindaje implementado en la macro (decisiones de robustez)
   144→   144→
   145→   145→A pedido del usuario, el código fue blindado contra:
   146→   146→
   147→   147→- **Datos no encontrados**: si no se puede identificar factura, cliente,
   148→   148→  fecha, tabla de productos, o total, el proceso se detiene **antes** de
   149→   149→  escribir nada en la base de datos, y se informa exactamente qué etiqueta
   150→   150→  faltó.
   151→   151→- **Duplicados**: antes de registrar, se verifica si el número de factura
   152→   152→  ya existe en la base. Si existe, se pregunta al usuario si desea
   153→   153→  sobrescribir; si confirma, se borran las filas viejas de esa factura
   154→   154→  antes de volver a cargarla. Nunca se acumulan copias duplicadas.
   155→   155→- **Filas de producto con datos inválidos**: si una fila tiene cantidad o
   156→   156→  valor no numérico, se omite solo esa fila puntual (no se aborta todo el
   157→   157→  proceso).
   158→   158→- **Errores inesperados de Excel/VBA**: capturados con `On Error`, se
   159→   159→  muestra código y descripción del error en vez de que la macro falle
   160→   160→  silenciosamente o deje datos a medio cargar.
   161→   161→- **Bucle infinito de seguridad**: si por algún motivo el recorrido de
   162→   162→  filas de productos supera un límite razonable (500 filas), se detiene
   163→   163→  solo, para no recorrer toda la hoja indefinidamente.
   164→   164→- **Trazabilidad**: cada línea registrada incluye, además de los 6 campos
   165→   165→  pedidos originalmente, columnas de auditoría: Total de la factura
   166→   166→  completa, **Hoja de Origen** (de qué hoja Excel vino el dato), **Fecha de
   167→   167→  Registro** (cuándo se ejecutó la macro), y **Usuario** (quién la ejecutó).
   168→   168→- **Sin emojis, tono profesional**: a pedido explícito, todos los mensajes
   169→   169→  (`MsgBox`) y comentarios del código se redactaron en tono formal, sin
   170→   170→  emojis ni símbolos informales.
   171→   171→- **Configuración editable centralizada**: todas las palabras clave que la
   172→   172→  macro busca (`FACTURA`, `CLIENTE`, `CODIGO`, `PRODUCTO`, `CANTIDAD`,
   173→   173→  `VALOR`, `TOTAL`) están en constantes (`Const`) agrupadas en una sección
   174→   174→  `CONFIGURACION` al inicio del módulo. Si la plantilla real usa palabras
   175→   175→  distintas (ej. "Importe" en vez de "Valor"), **solo se cambia el texto
   176→   176→  entre comillas de esa constante**, sin tocar el resto del código.
   177→   177→
   178→   178→## 7. Cómo funciona la búsqueda de datos (mecanismo explicado)
   179→   179→
   180→   180→La macro **no usa coordenadas de celda fijas**. Usa el método `.Find` de
   181→   181→VBA (el mismo motor que el "Buscar" de Excel, Ctrl+B) sobre el
   182→   182→`UsedRange` de la hoja:
   183→   183→
   184→   184→1. Busca el texto de cada etiqueta configurada (ej. "FACTURA") en
   185→   185→   cualquier celda de la hoja.
   186→   186→2. Una vez encontrada la etiqueta, **lee el valor de la celda vecina**
   187→   187→   (a la derecha, o si está vacía, la de abajo).
   188→   188→3. Para la tabla de productos: busca la fila que contiene los encabezados
   189→   189→   ("PRODUCTO", "CANTIDAD", "VALOR", "CODIGO") — esa fila es el ancla. A
   190→   190→   partir de la fila siguiente, recorre hacia abajo registrando cada
   191→   191→   producto, hasta encontrar una fila vacía o la palabra "TOTAL".
   192→   192→4. Para el Total general: busca la palabra "TOTAL" en la hoja y lee el
   193→   193→   valor numérico contiguo.
   194→   194→
   195→   195→Esto hace que la posición exacta no importe — solo que la palabra clave
   196→   196→exista en algún lugar de la hoja — y por eso funciona sin romperse aunque
   197→   197→la cantidad de productos (y por lo tanto la posición del Total) cambie de
   198→   198→una factura a otra.

   265→   265→## Código VBA completo (para copiar directo al módulo)
   266→   266→
   267→   267→```vba
   268→   268→Attribute VB_Name = "modRegistroFacturas"
   269→   269→Option Explicit
   270→   270→
   271→   271→'==========================================================================
   272→   272→'   SISTEMA DE REGISTRO AUTOMATICO DE FACTURAS
   273→   273→'   Modulo: modRegistroFacturas
   274→   274→'
   275→   275→'   PROPOSITO:
   276→   276→'   Lee los datos de la factura activa (buscando etiquetas de texto, no
   277→   277→'   posiciones fijas de celda) y los vuelca como filas individuales en la
   278→   278→'   hoja "BaseDeDatos", evitando duplicados y validando cada dato antes
   279→   279→'   de registrarlo.
   280→   280→'
   281→   281→'   COMO EDITAR ESTE MODULO SI LAS ETIQUETAS DE TU PLANTILLA SON DISTINTAS:
   282→   282→'   Todas las palabras que la macro busca estan centralizadas en la seccion
   283→   283→'   "CONFIGURACION" mas abajo. Si en tu plantilla real una etiqueta se
   284→   284→'   llama diferente (por ejemplo "Importe" en vez de "Valor", o "N° Comp."
   285→   285→'   en vez de "Factura"), cambia UNICAMENTE el texto entre comillas en esa
   286→   286→'   seccion. No es necesario tocar el resto del codigo.
   287→   287→'==========================================================================
   288→   288→
   289→   289→
   290→   290→'================== CONFIGURACION (EDITAR AQUI SI HACE FALTA) ==================
   291→   291→
   292→   292→' Etiqueta que identifica el numero de factura y direccion donde esta el dato
   293→   293→' real respecto a la etiqueta (0,1)=misma fila una columna a la derecha
   294→   294→Private Const ETQ_FACTURA      As String = "FACTURA"
   295→   295→
   296→   296→' Etiqueta del cliente
   297→   297→Private Const ETQ_CLIENTE      As String = "CLIENTE"
   298→   298→
   299→   299→' Etiquetas de la fila de encabezado de la tabla de productos
   300→   300→Private Const ETQ_CODIGO       As String = "CODIGO"
   301→   301→Private Const ETQ_PRODUCTO     As String = "PRODUCTO"
   302→   302→Private Const ETQ_CANTIDAD     As String = "CANTIDAD"
   303→   303→Private Const ETQ_VALOR        As String = "VALOR"     ' si tu plantilla usa "IMPORTE" o "SUBTOTAL", cambialo aqui
   304→   304→
   305→   305→' Etiqueta que marca el final de la tabla y el total general
   306→   306→Private Const ETQ_TOTAL        As String = "TOTAL"
   307→   307→
   308→   308→' Nombre de la hoja donde se acumulan los registros
   309→   309→Private Const HOJA_BD          As String = "BaseDeDatos"
   310→   310→
   311→   311→'================================================================================
   312→   312→
   313→   313→
   314→   314→'--------------------------------------------------------------------------
   315→   315→' SUB PRINCIPAL: Punto de entrada del boton "Registrar Factura"
   316→   316→'--------------------------------------------------------------------------
   317→   317→Sub RegistrarFactura()
   318→   318→
   319→   319→    Dim wsFactura As Worksheet
   320→   320→    Dim wsBD As Worksheet
   321→   321→    Dim numFactura As String
   322→   322→    Dim fechaEmision As Variant
   323→   323→    Dim cliente As String
   324→   324→    Dim filaHeader As Long
   325→   325→    Dim colCodigo As Long, colProducto As Long, colCantidad As Long, colValor As Long
   326→   326→    Dim totalGeneral As Variant
   327→   327→    Dim productosLeidos As Long
   328→   328→    Dim erroresValidacion As String
   329→   329→
   330→   330→    On Error GoTo ErrorHandler
   331→   331→
   332→   332→    Application.ScreenUpdating = False
   333→   333→    Application.EnableEvents = False
   334→   334→
   335→   335→    Set wsFactura = ActiveSheet
   336→   336→
   337→   337→    '--- 0. Validar que exista la hoja BaseDeDatos ---
   338→   338→    If Not ExisteHoja(HOJA_BD) Then
   339→   339→        MsgBox "No se encontro la hoja '" & HOJA_BD & "'." & vbCrLf & _
   340→   340→               "Verifique que el libro contenga la hoja de base de datos antes de continuar.", _
   341→   341→               vbCritical, "Hoja de base de datos no encontrada"
   342→   342→        GoTo Salir
   343→   343→    End If
   344→   344→    Set wsBD = ThisWorkbook.Sheets(HOJA_BD)
   345→   345→
   346→   346→    '--- 1. Capturar Numero de Factura ---
   347→   347→    numFactura = BuscarValorJunto(wsFactura, ETQ_FACTURA)
   348→   348→    If numFactura = "" Then
   349→   349→        erroresValidacion = erroresValidacion & "- No se pudo identificar el NUMERO DE FACTURA." & vbCrLf
   350→   350→    End If
   351→   351→
   352→   352→    '--- 2. Capturar Fecha de Emision (busca la primera celda con formato/valor de fecha) ---
   353→   353→    fechaEmision = BuscarFecha(wsFactura)

   372→   372→
   373→   373→    '--- 5. Verificar si la factura ya fue registrada (anti-duplicados) ---

   380→   380→                            vbExclamation + vbYesNo, "Factura duplicada detectada")

   383→   383→            GoTo Salir

   408→   408→    productosLeidos = ProcesarYGuardarProductos(wsFactura, wsBD, filaHeader, colCodigo, colProducto, _
   409→   409→                                                  colCantidad, colValor, numFactura, fechaEmision, _

   411→   411→

   446→   446→Private Function BuscarValorJunto(ws As Worksheet, etiqueta As String) As String
   447→   447→    Dim celda As Range

   449→   449→

   468→   468→'--------------------------------------------------------------------------
   469→   469→' Busca la primera celda de la hoja cuyo valor sea una fecha valida.

   471→   471→'--------------------------------------------------------------------------
   472→   472→Private Function BuscarFecha(ws As Worksheet) As Variant
   473→   473→    Dim c As Range
   474→   474→
   475→   475→    For Each c In ws.UsedRange.Cells
   476→   476→        If Not IsEmpty(c.Value) Then
   477→   477→            If IsDate(c.Value) Then
   478→   478→                ' Se descartan numeros sueltos que Excel podria interpretar como fecha por error
   479→   479→                If c.Value > 0 And Len(Trim(CStr(c.Value))) >= 6 Then
   480→   480→                    BuscarFecha = CDate(c.Value)
   481→   481→                    Exit Function
   482→   482→                End If
   483→   483→            End If
   484→   484→        End If
   485→   485→    Next c
   486→   486→
   487→   487→    BuscarFecha = Null
   488→   488→End Function

   492→   492→' Localiza la fila de encabezado de la tabla de productos y las columnas

   495→   495→'--------------------------------------------------------------------------
   496→   496→Private Function LocalizarEncabezadoTabla(ws As Worksheet, ByRef filaHeader As Long, _
   497→   497→        ByRef colCodigo As Long, ByRef colProducto As Long, ByRef colCantidad As Long, _
   498→   498→        ByRef colValor As Long) As Boolean
   499→   499→
   500→   500→    Dim celdaProducto As Range
   501→   501→    Dim celdaCantidad As Range
   502→   502→    Dim celdaValor As Range
   503→   503→    Dim celdaCodigo As Range
   504→   504→
   505→   505→    On Error Resume Next
   506→   506→    Set celdaProducto = ws.UsedRange.Find(What:=ETQ_PRODUCTO, LookIn:=xlValues, LookAt:=xlPart, MatchCase:=False)
   507→   507→    On Error GoTo 0

   521→   521→    On Error GoTo 0
   522→   522→

   526→   526→    End If
   527→   527→
   528→   528→    colCantidad = celdaCantidad.Column
   529→   529→    colValor = celdaValor.Column
   530→   530→    If Not celdaCodigo Is Nothing Then
   531→   531→        colCodigo = celdaCodigo.Column
   532→   532→    Else

   541→   541→' Busca la etiqueta TOTAL en la hoja (a partir de la fila de la tabla hacia

   544→   544→Private Function BuscarTotalGeneral(ws As Worksheet, etiqueta As String) As Variant
   545→   545→    Dim celda As Range
   546→   546→    Dim valor As Variant
   547→   547→
   548→   548→    On Error Resume Next
   549→   549→    Set celda = ws.UsedRange.Find(What:=etiqueta, LookIn:=xlValues, LookAt:=xlPart, MatchCase:=False, SearchDirection:=xlNext)
   550→   550→    On Error GoTo 0
   551→   551→
   552→   552→    If celda Is Nothing Then
   553→   553→        BuscarTotalGeneral = Null
   554→   554→        Exit Function
   555→   555→    End If
   556→   556→
   557→   557→    valor = celda.Offset(0, 1).Value
   558→   558→    If Not IsNumeric(valor) Or valor = "" Then
   559→   559→        valor = celda.Offset(1, 0).Value
   560→   560→    End If
   561→   561→
   562→   562→    If IsNumeric(valor) And valor <> "" Then
   563→   563→        BuscarTotalGeneral = CDbl(valor)
   564→   564→    Else
   565→   565→        BuscarTotalGeneral = Null
   566→   566→    End If

   571→   571→' Recorre las filas de productos desde justo debajo del encabezado hasta
   572→   572→' encontrar una fila vacia o la palabra TOTAL. Cada fila valida se vuelca
   573→   573→' a la BaseDeDatos. Devuelve la cantidad de productos registrados.
   574→   574→'--------------------------------------------------------------------------
   575→   575→Private Function ProcesarYGuardarProductos(wsFactura As Worksheet, wsBD As Worksheet, _
   576→   576→        filaHeader As Long, colCodigo As Long, colProducto As Long, colCantidad As Long, _
   577→   577→        colValor As Long, numFactura As String, fechaEmision As Variant, cliente As String, _
   578→   578→        totalGeneral As Variant) As Long
   579→   579→
   580→   580→    Dim i As Long
   581→   581→    Dim filaDestino As Long
   582→   582→    Dim contador As Long
   583→   583→    Dim nombreProducto As String
   584→   584→    Dim cantidadProd As Variant
   585→   585→    Dim valorProd As Variant
   586→   586→
   587→   587→    contador = 0
   588→   588→    i = filaHeader + 1
   589→   589→
   590→   590→    Do While Trim(CStr(wsFactura.Cells(i, colProducto).Value)) <> ""
   591→   591→
   592→   592→        nombreProducto = Trim(CStr(wsFactura.Cells(i, colProducto).Value))
   593→   593→
   594→   594→        ' Si la fila actual es la fila del TOTAL, se termina el recorrido
   595→   595→        If UCase(nombreProducto) = UCase(ETQ_TOTAL) Then Exit Do
   596→   596→
   597→   597→        cantidadProd = wsFactura.Cells(i, colCantidad).Value
   598→   598→        valorProd = wsFactura.Cells(i, colValor).Value
   599→   599→
   600→   600→        ' Validacion de fila: si cantidad o valor no son numericos, se omite
   601→   601→        ' esa fila puntual (no se detiene todo el proceso) y se deja constancia
   602→   602→        If IsNumeric(cantidadProd) And IsNumeric(valorProd) Then
   603→   603→            filaDestino = wsBD.Cells(wsBD.Rows.Count, 1).End(xlUp).Row + 1
   604→   604→
   605→   605→            wsBD.Cells(filaDestino, 1).Value = numFactura
   606→   606→            wsBD.Cells(filaDestino, 2).Value = fechaEmision
   607→   607→            wsBD.Cells(filaDestino, 2).NumberFormat = "dd/mm/yyyy"
   608→   608→            wsBD.Cells(filaDestino, 3).Value = cliente
   609→   609→            wsBD.Cells(filaDestino, 4).Value = CDbl(cantidadProd)
   610→   610→            wsBD.Cells(filaDestino, 5).Value = nombreProducto
   611→   611→            wsBD.Cells(filaDestino, 6).Value = CDbl(valorProd)
   612→   612→            wsBD.Cells(filaDestino, 6).NumberFormat = "#,##0.00"
   613→   613→            wsBD.Cells(filaDestino, 7).Value = totalGeneral
   614→   614→            wsBD.Cells(filaDestino, 7).NumberFormat = "#,##0.00"
   615→   615→            wsBD.Cells(filaDestino, 8).Value = wsFactura.Name          ' Hoja de origen (trazabilidad)
   616→   616→            wsBD.Cells(filaDestino, 9).Value = Now                     ' Fecha/hora de registro
   617→   617→            wsBD.Cells(filaDestino, 9).NumberFormat = "dd/mm/yyyy hh:mm"
   618→   618→            wsBD.Cells(filaDestino, 10).Value = Environ("Username")    ' Usuario que registro
   619→   619→
   620→   620→            contador = contador + 1
   621→   621→        End If
   622→   622→
   623→   623→        i = i + 1
   624→   624→
   625→   625→        ' Salvaguarda anti-bucle-infinito: si por algun motivo se supera un
   626→   626→        ' limite razonable de filas, se detiene para no recorrer toda la hoja
   627→   627→        If i - filaHeader > 500 Then Exit Do
   628→   628→    Loop
   629→   629→
   630→   630→    ProcesarYGuardarProductos = contador
   631→   631→End Function
